VNet이란?

        
클라우드에서 VM들이 들어가는 사설 네트워크입니다. AWS는 VPC, Azure는 VNet, GCP는 VPC라고 부르며 CB-Tumblebug에서는 이를 VNet으로 통일해 표현합니다.


        

          

            1
            VM에서 vNetId 확인
            예: aws-us-west-vnet
          

          

            2
            VNet 정보 조회
            cidrBlock: 10.0.0.0/16
          

          

            3
            SG 규칙에 적용
            10.0.0.0/16만 포트 접근 허용
          

        


        

          CSP별 차이: AWS·Azure·NCP처럼 VNet/VPC CIDR이 있는 경우 그 값을 사용하고, GCP처럼 VPC 자체 CIDR이 없는 경우에는 VM이 속한 Subnet CIDR을 사용해야 합니다.
